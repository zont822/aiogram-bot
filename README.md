# Telegram Bot for Service Booking & Application Management / Асинхронний Telegram-бот для бронювання послуг

---

## 🇺🇦 Українська версія

**Опис проєкту**

Асинхронний Telegram-бот для автоматизації запису клієнтів на послуги, автоматичного відправлення нагадувань про візит та зручного керування заявками через панель адміністратора. Проєкт розроблено на сучасному стеку Python із дотриманням чистої архітектури (роутери, FSM, асинхронні запити до БД).

**🛠 Технологічний стек:**

* Мова розробки: Python 3.11+
* Фреймворк: aiogram 3.x (Router, FSMContext)
* База даних: aiosqlite (SQLite)
* Конфігурація: python-dotenv

**✨ Повний перелік можливостей:**

1. **Для користувачів:**
* **Покроковий запис (FSM):** Збір інформації через інтерактивну форму — ім'я, номер телефону, послуга, дата та зручний час.
* **Автоматичні нагадування:** Система фонових задач, яка заздалегідь надсилає клієнту сповіщення про майбутній запис, щоб він не забув про візит.
* **Статуси та сповіщення:** Отримання миттєвих push-повідомлень у чат при зміні стану заявки (підтверджено / відхилено).
* **Перегляд своїх записів:** Можливість переглянути активні та завершені бронювання.


2. **Для адміністраторів:**
* **Панель управління:** Перегляд нових, підтверджених та відхилених заявок у формі зручного списку.
* **Миттєві сповіщення про нові записи:** Адмін одразу отримує повідомлення в Telegram при створенні нової заявки клієнтом.
* **Управління статусами в 1 клік:** Інлайн-кнопки під повідомленням для швидкого підтвердження або скасування запису.
* **Синхронізація з БД:** Автоматична зміна статусу запису в SQLite та інформування користувача про прийняте рішення.



**📁 Структура проєкту:**

* main.py — точка входу, ініціалізація бота, диспетчера та фонових задач (нагадувань).
* handlers/ — роутери для обробки команд, повідомлень та дій користувачів.
* forms/ — стани FSM для покрокового збору інформації.
* bazadanyh.sql — схема та асинхронні запити до бази даних.

**🚀 Локальний запуск:**

1. Склонувати репозиторій: git clone <посилання_на_репозиторій>
2. Перейти в папку проєкту: cd telegram-bot-example
3. Створити та активувати віртуальне оточення: python -m venv .venv
4. Встановити залежності: pip install -r requirements.txt
5. Створити файл .env і додати BOT_TOKEN та ADMIN_ID.
6. Запустити бота: python main.py

## 🇷🇺 Русская версия

**Описание проекта**

Асинхронный Telegram-бот для автоматизации записи клиентов на услуги, автоматической отправки напоминаний о визите и удобного управления заявками через панель администратора. Проект разработан на современном стеке Python с соблюдением чистой архитектуры (роутеры, FSM, асинхронные запросы к БД).

**🛠 Технологический стек:**

* Язык разработки: Python 3.11+
* Фреймворк: aiogram 3.x (Router, FSMContext)
* База данных: aiosqlite (SQLite)
* Конфигурация: python-dotenv

**✨ Полный список возможностей:**

1. **Для пользователей:**
* **Пошаговая запись (FSM):** Сбор информации через интерактивную форму — имя, номер телефона, услуга, дата и удобное время.
* **Автоматические напоминания:** Система фоновых задач, которая заранее отправляет клиенту уведомление о предстоящей записи, чтобы он не забыл о визите.
* **Статусы и уведомления:** Получение мгновенных push-уведомлений в чат при изменении состояния заявки (подтверждена / отклонена).
* **Просмотр своих записей:** Возможность посмотреть активные и завершенные бронирования.


2. **Для администраторов:**
* **Панель управления:** Просмотр новых, подтвержденных и отклоненных заявок в виде удобного списка.
* **Мгновенные уведомления о новых записях:** Админ сразу получает сообщение в Telegram при создании новой заявки клиентом.
* **Управление статусами в 1 клик:** Инлайн-кнопки под сообщением для быстрого подтверждения или отмены записи.
* **Синхронизация с БД:** Автоматическая смена статуса записи в SQLite и информирование пользователя о принятом решении.



**📁 Структура проекта:**

* main.py — точка входа, инициализация бота, диспетчера и фоновых задач (напоминаний).
* handlers/ — роутеры для обработки команд, сообщений и действий пользователей.
* forms/ — состояния FSM для пошагового сбора информации.
* bazadanyh.sql — схема и асинхронные запросы к базе данных.

**🚀 Локальный запуск:**

1. Склонировать репозиторий: git clone <ссылка_на_репозиторий>
2. Перейти в папку проекта: cd telegram-bot-example
3. Создать и активировать виртуальное окружение: python -m venv .venv
4. Установить зависимости: pip install -r requirements.txt
5. Создать файл .env и добавить BOT_TOKEN и ADMIN_ID.
6. Запустить бота: python main.py
